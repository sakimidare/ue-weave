# 日志编号

[返回使用手册](usage.md)

终端使用 `error[E0001]: …`、`warning[W0001]: …` 和 `note[N0001]: …`。
正常识别和格式处理使用 note，仅在 `--verbose` 时显示。warning 用于下载失败、内容变化和格式不支持等情况，默认按编号汇总。
网络重试提示 N0028、详细日志入口提示 N0029 和解释入口提示 N0030 按运行情况直接显示。
详细输出包含相关文字或标签编号、属性、原值和处理结果。长片段显示前 180 个字符。
`--json` 的 `code` 与终端编号一致。资源下载警告包含 `error_code`，标明具体失败原因。

日志写入标准错误，JSON 运行结果写入标准输出。

终端中错误显示为红色，警告为黄色，提示为青色，处理进度为绿色。使用 `--color auto|always|never` 控制颜色，默认 `auto`：连接终端时启用，重定向时使用纯文本。`NO_COLOR` 环境变量可关闭自动颜色；命令行的 `always`、`never` 优先。JSON 运行结果保持纯文本。

## 开发约定

`error.rs` 中的 `RecoverError`、`AssetError`、`NetworkKind` 均为枚举，使用 thiserror 定义消息。
`diagnostic/warning.rs` 的 `WarningKind` 定义警告，`diagnostic/note.rs` 的 `NoteKind` 定义提示。`Diagnostic` 携带类型及详情。
警告使用 W0001 起的独立编号，提示使用 N0001 起的独立编号。新增类型在所属类别末尾分配编号；已有编号保持含义稳定。

`--explain CODE` 由 clap 解析，解释正文随程序编译，来源为 [编号解释](explanations.md)。新增编号时同步补充含义、例子和处理方法；测试检查编号覆盖情况。
