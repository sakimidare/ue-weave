# 编号解释

运行 `ue-weave --explain N0002` 查看一个编号。E 表示错误，W 表示需要检查的警告，N 表示处理提示。

## E0001 命令参数有误

命令缺少必要选项，或同时使用了相互冲突的选项。程序会指出具体参数。

例子：`ue-weave --input page.html` 缺少输出目录。

处理：补成 `ue-weave --input page.html --output output/`。用 `ue-weave --help` 查看选项。

## E0002 配置文件读取失败

程序无法打开 `--site-config` 或 `--headers-file` 指定的文件。

例子：`--site-config selectors.json` 指向了一个不存在的文件。

处理：检查文件位置和读取权限；相对路径从运行命令的目录开始计算。

## E0003 配置内容有误

选择器或 HTTP header 配置文件已找到，但其中的 JSON 或字段内容有误。header 文件需要使用对象，字段值需要是字符串。

例子：`{"content": ".Article_Content",}` 多了末尾逗号。

处理：改成 `{"content": ".Article_Content"}`，再检查错误消息指出的字段。

## E0004 正文 JSON 内容有误

`--input-ir` 的文件需要符合 ue-weave 的正文格式。消息中的字段路径指出检查失败的位置。

例子：手工编辑时把 `"blocks": []` 写成了 `"blocks": "正文"`。

处理：将 blocks 保持为数组，文字放在段落内。可先导出 `--formats json`，参照生成的文件编辑。

## E0005 本地文件读取失败

程序无法读取输入文件，也可能是重新导出 JSON 时找不到本地图片或附件。

例子：在另一个目录执行 `--input page.html`，当前目录没有 page.html。

处理：使用正确的绝对路径；重新导出时检查消息列出的资源文件，必要时用 `--asset-root` 指定资源目录。

## E0006 正文选择器写法有误

选择器用于寻找网页中的标签，其括号、引号等需要配对。

例子：`--selector 'content=div['` 中的方括号没有写完。

处理：例如改用 `--selector 'content=.Article_Content'`；类名前加点，ID 前加井号。

## E0007 找不到正文

已读取网页，但选择器没有匹配到正文。返回的页面也可能是登录页、错误页或跳转提示页。

例子：正文标签为 `<div class="news-body">`，当前选择器却是 `.Article_Content`。

处理：检查网页实际内容，再使用 `--selector 'content=.news-body'`。只有 JavaScript 运行后才出现的正文，需要提供已经包含正文的 HTML 文件。

## E0008 输出目录创建失败

程序无法创建输出目录。

例子：`--output output/`，但 output 已是一个普通文件。

处理：选择一个可写目录，例如 `--output article-output/`，或调整现有目录权限。

## E0009 输出文件写入失败

正文已处理，保存文档时发生错误。已保存的其他文件可能仍在输出目录中。

例子：reconstructed.html 为只读文件，或磁盘空间已满。

处理：检查消息中的文件路径、写入权限和剩余空间，然后重新运行。

## E0010 JSON 生成失败

程序在把结果写成 JSON 文本时遇到了错误。

例子：错误消息中的 file 为 stdout，表示终端 JSON 结果生成失败。

处理：保留完整错误消息和触发命令，用相同输入复现后提交问题，方便检查程序的数据转换。

## E0011 找不到这个编号

`--explain` 查询的编号没有收录在当前程序中。

例子：`ue-weave --explain N9999` 会得到此错误。

处理：复制日志中方括号内的编号，例如 `ue-weave --explain N0002`。编号保留四位数字；字母大小写均可。

## E0012 正文 JSON 读取失败

文件内容无法读成所需的 JSON 数据，消息会说明格式错误的位置。

例子：`{"blocks": []` 缺少最后一个右花括号。

处理：根据消息中的行列补齐括号、引号或逗号，再重新执行 --input-ir。

## E0013 网络客户端创建失败

程序在准备网络连接时遇到错误，请求尚未发出。

例子：本机 TLS 配置导致网络客户端初始化失败，消息会列出底层原因。

处理：检查消息中的具体原因和系统网络配置；提交问题时附上完整错误消息。

## E0014 HTTP header 配置错误

HTTP header 名称、值或命令行的 NAME=VALUE 格式有误，或尝试覆盖由 HTTP 客户端管理的 header。文件读取失败对应 E0002，JSON 格式或字段值类型错误对应 E0003。

例子：`ue-weave URL --header 'Referer'` 缺少 `=VALUE`，或使用 `--header 'Host=internal'`。

处理：使用 `--header 'NAME=VALUE'`，或使用 JSON 对象文件。不要设置 `Host`、`Content-Length`、`Connection` 和 `Transfer-Encoding`。

## E0015 网站限制访问

服务器返回访问提示页，明确要求校内网络、登录或访问权限。

例子：页面显示“您当前 ip 并非校内地址，该信息仅允许校内地址访问”。

处理：连接校园网络后重试。域名解析结果变化时，可用 `--resolve jwc.seu.edu.cn=校内IP --allow-private-network` 固定已确认的连接地址。网站要求登录时，使用自己已有的登录凭据。`--allow-private-network` 只允许连接私网地址。

## E0016 原网页正文为空

已找到正文容器，其中没有文字、链接或图片等内容。

例子：服务器返回 `<article class="detail-body"><div></div></article>`，仅包含空标签。

处理：打开原网页确认正文是否存在，或使用 `--selector content=CSS` 选择实际正文。空容器没有可导出的内容。

## E0017 日志开关无效

`--log` 的写法无法解析，或使用了未知的类别或级别。

例子：`--log style=loud` 使用了不存在的级别；`--log asset=list` 使用了不存在的类别。

处理：使用 `[topic[.severity]=]level`，省略类别时作用于全部诊断，例如 `--log summary`。领域可用：`all`、`progress`、`warning`、`note`、`network`、`encoding`、`image`、`attachment`、`style`、`structure`、`integrity`、`inference`、`word`，也可以直接写编号如 `W0014`。级别可用：`off`、`summary`、`list`、`context`。需要按严重度细分时写成 `style.warning=list` 或 `style.note=off`。

## E0101 请求超时

网页或资源在设定时间内没有完成响应。

例子：服务器需要 40 秒响应，而默认超时为 30 秒。

处理：检查网络，或添加 `--timeout 60`。超时上限为 120 秒；`--retries 3` 可增加重试次数。

## E0102 域名解析失败

程序没有查到网站域名对应的网络地址。

例子：网址中的 example.org 拼写错误，或当前 DNS 服务没有响应。

处理：核对域名，检查本机 DNS 和网络连接，再运行同一命令。

## E0103 HTTPS 连接校验失败

程序无法建立可信的加密连接，详细消息会说明证书或连接方面的问题。

例子：网站证书已过期，或本机日期错误导致证书被判断为尚未生效。

处理：检查系统日期、网站证书和 HTTPS 代理设置。当前程序使用内置根证书；单位代理替换证书时，请联系网络管理员确认可用的访问方式。

## E0104 无法连接服务器

地址已经确定，但连接没有建立。

例子：网站服务器关闭了 HTTPS 端口，或当前网络无法到达该地址。

处理：检查网址端口、网络连接和服务器状态，稍后重试。

## E0105 响应读取失败

连接已经建立，但页面或文件没有完整接收。

例子：附件下载到一半，服务器断开连接。

处理：重新运行命令；网络不稳定时可使用 `--retries 3`。查看详情中的 URL，确认出问题的是正文还是资源。

## E0106 服务器返回错误状态

服务器明确返回了失败状态，日志会列出 HTTP 状态码。

例子：404 表示链接对应的页面不存在；403 表示服务器拒绝访问；503 常见于服务暂时不可用。

处理：404 时核对网址，403 时确认页面的公开访问方式，503 时稍后重试。

## E0107 下载内容超过大小限制

单个页面或资源超过了程序的读取上限，目前为 64 MiB。

例子：一个 100 MiB 的附件会触发此错误。

处理：导出正文时保留附件在线链接，按需单独下载大文件。检查 URL 是否意外指向了大型文件。

## E0108 URL 格式有误

程序无法把给出的地址解析成可请求的 URL，或地址使用了 HTTP/HTTPS 以外的协议、在 URL 内包含用户名或密码。

例子：`https://` 后面没有网站域名。

处理：提供完整的 HTTP/HTTPS 地址，例如 `https://example.org/article.html`；需要身份信息时通过 HTTP header 提供。--allow-private-network 只控制网段访问。

## E0109 地址属于受限制的网段

请求地址或跳转后的地址落在私网、回环、链路本地等网段，当前命令没有开启私网访问。

例子：127.0.0.1 是本机地址。TUN 的 Fake-IP 模式也可能把公开域名解析到 198.18.x.x，触发此检查。

处理：确认地址用途后，给抓取命令添加 `--allow-private-network`。使用 TUN 时也可调整 DNS 为返回网站真实地址。查看日志里的地址可帮助判断原因。

## E0110 网络请求失败

请求发生了其他网络错误，详细消息记录了具体原因。

例子：服务器返回无法解析的 HTTP 响应头，请求客户端报告协议错误。客户端初始化失败使用 E0013。

处理：检查消息中的 URL 和底层错误，确认网络配置；提交问题时附上完整消息及命令。

## E0111 重定向次数超过上限

同一次请求已跟随 10 次跳转，服务器仍要求继续跳转。

例子：页面 A 跳到页面 B，页面 B 又跳回 A，形成循环。

处理：检查跳转链接和登录状态，尽量使用最终页面地址。--allow-private-network 不改变跳转次数限制。

## E0201 资源内容类型不符合要求

收到的文件内容与所需的资源类型不符，程序没有将它保存为预期资源。

例子：图片地址返回了一段登录页 HTML。

处理：在浏览器中检查资源地址，确认它能直接返回图片或附件；必要时更新文章中的链接。

## E0202 资源地址协议不支持下载

下载功能使用 HTTP 或 HTTPS 地址。

例子：附件链接是 `file:///home/user/report.pdf`。

处理：在线资源改用完整的 HTTP/HTTPS 链接；本地资源在 JSON 再导出时通过资源目录提供。

## E0203 资源保存失败

资源已请求，但本地文件写入失败。

例子：images/ 目录没有写入权限。

处理：检查错误消息中的路径、目录权限及磁盘空间，再重新下载。

## E0204 无法分配资源文件名

程序尝试生成多个文件名后，仍与输出目录中的文件冲突。

例子：同一个资源名称对应的候选文件名都已被占用。

处理：换一个新的输出目录重新导出，或整理当前目录中已有的资源文件。

## E0301 HTML 标签记录格式有误

JSON 中的 original_nodes 保存原网页的标签和文字记录，其中某个值的格式无法读取。

例子：children 应为数组，却被改成 `"children": 12`。

处理：根据错误中的字段修正值类型。编辑正文主要修改 blocks，原网页记录可保持原样。

## E0302 HTML 标签记录缺少编号

original_nodes 中每条记录都需要一个非空的 id。

例子：`{"id":"","type":"text","text":"通知"}` 的 id 为空。

处理：给记录填写唯一编号，例如 n12，并同步修改引用它的 source_nodes。

## E0303 HTML 标签编号重复

两条原网页记录使用了相同 id，程序无法确定正文引用的是哪一条。

例子：两个不同段落都被写成 `"id":"n12"`。

处理：为它们分配不同编号，并检查 parent、children 和 source_nodes 中的对应引用。

## E0304 HTML 记录类型不认识

original_nodes 的 type 需要使用 element、text、comment 或 other。element 表示标签，text 表示文字。

例子：段落标签写成了 `"type":"paragraph"`。

处理：标签记录使用 `"type":"element","tag":"p"`。正文 blocks 中的 paragraph 表示段落。

## E0305 子标签关系有误

children 列出的记录不存在，或那条记录的 parent 指向了别处。

例子：n1 的 children 包含 n2，但 n2 的 parent 是 n3。

处理：让两端对应起来：n1 包含 n2 时，n2 的 parent 应为 n1。

## E0306 父标签关系有误

parent 指向的记录不存在，或父标签的 children 没有列出当前记录。

例子：n2 的 parent 为 n1，但 n1 的 children 是空数组。

处理：检查父标签编号，并将当前记录编号加入正确的 children 数组。

## E0307 HTML 标签关系重复或形成循环

一个标签被重复列为子标签，或标签互相包含，无法形成正常的层级。

例子：n1 包含 n2，同时 n2 又包含 n1。

处理：删除重复的 children 项，按网页实际的外层、内层关系整理 parent 和 children。

## E0308 来源编号需要数组

source_nodes 用数组列出正文对应的原网页记录。

例子：`"source_nodes":"n12"` 的值类型不对。

处理：改为 `"source_nodes":["n12"]`。新写的正文没有原网页来源时，可以省略该字段。

## E0309 来源编号需要字符串

引用的编号需要与 original_nodes 的 id 一样使用字符串。

例子：`"source_nodes":[12]` 中使用了数字。

处理：填写实际存在的编号，例如 `"source_nodes":["n12"]`。

## E0310 来源编号不存在

正文引用了一个编号，但 original_nodes 中找不到对应记录。

例子：段落写着 `"source_nodes":["n99"]`，文件中却没有 id 为 n99 的记录。

处理：修正为实际对应的编号。手工新增且没有原网页来源的内容可以省略 source_nodes。

## W0001 无法识别网页编码

网页声明的字符编码名称无法识别。程序会尝试其他可用信息读取文字。

例子：网页写了 `<meta charset="unknown-charset">`。

处理：检查导出文字是否正常。本地文件可用文本编辑器另存为 UTF-8，并将 charset 改成 UTF-8。

## W0002 部分文字解码失败

输入字节无法按选定编码读成文字，某些位置可能出现替代字符 �。

例子：文件实际为 GBK，却声明为 UTF-8，中文可能变成乱码。

处理：按文件真实编码打开，再另存为 UTF-8 后导出。用 --verbose 查看详情。

## W0003 导出正文的文字或顺序发生变化

程序比较原网页与还原结果时，发现文字内容或先后顺序不一致，需要人工核对。

例子：原文依次为“报名”“审核”，还原结果变成“审核”“报名”。

处理：加 --verbose 查看差异附近的 HTML 和输出文字，核对相关段落；保留能复现的 HTML 供修复使用。

## W0004 导出资源的地址或数量发生变化

资源检查发现地址或数量与预期不一致，可能影响图片显示或附件访问。

例子：原文有两张不同图片，结果只保留了一张。

处理：用 --verbose 查看涉及的资源，核对输出中的图片和链接是否齐全、是否可打开。

## W0005 图片下载失败

某张图片没有保存到本地；正文会继续使用可用的在线地址。

例子：图片服务器返回 404，而文章正文仍能正常读取。

处理：检查日志里的图片 URL 和 E 编号。例如 E0101 表示超时，可增加 --timeout 后重试。

## W0006 附件下载失败

某个附件没有保存到本地，文章仍保留附件链接。

例子：申请表链接已失效，服务器返回 404。

处理：检查日志里的 URL 和 E 编号，确认链接是否有效；可先导出正文，再按需处理附件。

## W0007 附件属性无法解析

网页额外保存的附件说明格式有误。程序仍会尝试从普通链接中提取附件信息。

例子：`sudyfile-attr='{name:申请表.doc}'` 缺少 JSON 所需的引号。

处理：检查导出的附件名称和链接。若链接正确即可使用；名称有误时可以在正文 JSON 中调整。

## W0008 网页基址无效

网页的 base 标签指定了一个无法使用的地址，影响相对链接的补全。

例子：`<base href="http://[">` 无法组成完整地址。

处理：检查导出后的图片及附件链接；本地 HTML 可将 base 的 href 改为正确的网页地址。

## W0009 部分网页结构尚未支持

遇到了当前程序尚未完整处理的标签或结构，相关排版需要检查。

例子：iframe 播放器转换为普通链接；SVG、MathML 保留可提取的文字；figure、details 的内容继续保留，容器排版需要检查。

处理：加 --verbose 查看对应 HTML，检查该处的文字和图片。提交该小段 HTML 有助于补充支持。

## W0010 目标格式尚未支持此排版

目标格式对某种排版的支持有限，输出可能采用简化表达。

例子：Markdown 的普通表格无法直接表达复杂的合并单元格。

处理：检查对应位置；需要更完整的表格展示时，同时导出 HTML，命令添加 `--formats markdown,html`。

## W0011 样式声明格式错误

标签的 style 中有无法读成“属性: 值”的声明。

例子：`style="color red; text-align: right"` 中 color 后缺少冒号。

处理：本地 HTML 可修正为 `color: red`；用 --verbose 查看具体声明和对应文字。

## W0012 已过滤事件属性或不可用地址

输出去掉了点击脚本等事件属性，或无法用于正常链接的地址。

例子：`<a href="javascript:alert(1)">查看通知</a>` 中的脚本地址会被过滤。

处理：检查该处是否需要一个实际网址；需要时将链接改为文章的 HTTP/HTTPS 地址。

## W0013 已过滤不可用样式

某个样式值未通过输出检查，最终文档不使用该值。

例子：`width: expression(alert(1))` 含有脚本式写法。

处理：用 --verbose 查看属性及原值；需要固定宽度时改成明确尺寸，例如 `width: 120px`。

## W0014 此样式尚未支持

程序识别到了样式声明，但尚未把该属性转换为输出格式。

例子：文字设置了 `text-shadow: 1px 1px gray`，导出时阴影可能不保留。

处理：查看 --verbose 中的属性名，检查视觉效果；需要保留时可在导出的 HTML 中补充样式。

## W0015 资源文件类型或文件名已调整

程序根据收到的内容调整资源保存方式或文件名。详情会说明具体调整。

例子：网址以 .jpg 结尾，文件内容实际是 PNG，保存时采用匹配的扩展名。

处理：检查本地资源是否能打开，以及正文链接是否指向该文件。

## W0016 检测到零宽字符

文字中含有通常看不见的字符，它可能来自编辑器占位，也可能有实际文字用途。

例子：“报名”两字之间夹着 U+200B，外观仍像“报名”，复制和搜索却可能不同。

处理：检查该处复制、搜索的结果；确认多余后，可在正文 JSON 的文字中删除该字符。

## W0017 已过滤脚本或嵌入内容

正文含有 script、style、object 或 embed 标签，对应部分已过滤。iframe、video、audio 转为链接时使用 W0009。

例子：`<object data="player.swf"></object>` 没有进入导出的正文。

处理：检查原网页该处是否有重要内容；需要时在文章中补上播放器或文档的普通链接。

## W0018 自定义列表标记需要检查

列表使用了编辑器自定义的编号或项目符号，导出后的标记可能需要调整。

例子：原列表用圈号“①②③”，目标格式可能显示常规数字。

处理：核对列表顺序和标记。对标记有要求时，在导出文件中调整列表样式。

## N0001 检测到 Word 排版标记

网页含有 Word 常用的类名、属性或标签，程序据此识别可转换的格式。

例子：`<p class="MsoNormal">报名通知</p>` 中的 MsoNormal 常见于 Word 粘贴内容。

处理：通常无需操作；检查导出的段落、列表和表格即可。

## N0002 已将末尾段落识别为署名

文章末尾的短段落采用右对齐，内容像单位名称或日期，程序将它标为署名。文字继续保留，具体对齐效果取决于输出设置。

例子：文章末尾出现 `<p style="text-align: right">东南大学教务处</p>`，随后是右对齐的“2026年9月16日”。这两段会被判断为署名内容。

处理：判断正确时无需操作。如果该段实际是正文，可用 --no-inference 关闭自动判断；这也会关闭标题和缩进推断。也可导出 JSON 后单独调整该段，再用 --input-ir 导出。

## N0003 检测到空段落

段落没有可见文字，可能由换行标签或空白字符组成。是否保留由输出设置决定。

例子：`<p><br></p>` 在网页中通常占据一行。

处理：需要紧凑正文时可选 --profile aggressive；需要保留留白时检查保守档的输出。

## N0004 已将 PDF 阅读器转为附件链接

程序识别到网页内的 PDF 阅读器，并提取了其中的文档地址。

例子：文章内嵌“招生简章.pdf”的阅读区域，导出后以 PDF 链接呈现。

处理：点击链接检查文档；需要保存 PDF 时添加 --download-attachments。

## N0005 已转换 VML 图片尺寸

Word 的 VML 图片尺寸已转换为正文中可用的图片尺寸。VML 是部分旧版 Office 网页使用的图形标签。

例子：图片宽度为 72pt，换算后为 96px。

处理：通常无需操作；检查输出图片的大小和比例。

## N0006 已转换 VML 图片

程序从 Word 的 VML 标签中提取图片地址，生成普通图片内容。

例子：`<v:imagedata src="photo.png">` 提供的 photo.png 被作为图片保留。

处理：确认图片能正常显示；需要本地文件时添加 --download-images。

## N0007 已移除附件图标

附件前的 Word、PDF 等小图标已去掉，附件文字和链接继续保留。

例子：`<img class="sudy-attachment-icon" src="icon_doc.gif">` 后面是“申请表.doc”链接，输出保留申请表链接。

处理：通常无需操作；点击附件名称确认地址正确即可。

## N0008 已调整表格合并范围

单元格跨行数量已按实际行数和分组范围整理。

例子：`rowspan="0"` 表示延伸到当前行组末尾，程序会计算具体跨几行。

处理：检查表格合并后的对应关系，尤其关注表头和分组边界。

## N0009 检测到 Office 样式

style 中出现了 Office 专用的 mso- 属性，程序会记录并尝试处理可识别内容。

例子：`mso-pagination: widow-orphan` 是 Word 的分页相关声明。

处理：通常无需操作；用 --verbose 查看属性，按需要检查对应段落。

## N0010 已将连续文字组合为段落

容器中直接出现的文字和行内标签被归入一个段落，方便后续编辑。

例子：`<div>请<strong>按时</strong>报名<p>地点见下文</p></div>` 中，“请按时报名”形成独立段落。

处理：检查段落分隔是否符合原文意思。

## N0011 已计算相对行距

按字号比例设置的行距已转换成程序可使用的行距表示。

例子：`line-height: 150%` 表示行高约为字号的 1.5 倍。

处理：检查输出的行间距离；最终是否保留还取决于所选格式预设。

## N0012 检测到 Word 段落格式

段落带有 Word 粘贴内容常见的排版特征，程序据此辅助判断段落结构。

例子：带 MsoNormal 类名的段落同时声明了 mso- 开头的样式。

处理：检查段落划分和缩进是否合适；需要关闭自动判断时使用 --no-inference。

## N0013 网页未提供此文档属性

网页没有记录某项原文档信息，该项保持未知。

例子：HTML 只包含文章段落，没有原 Word 文件的纸张大小。

处理：需要纸张大小等排版设置时，在最终排版文件中自行指定，或向作者索取原文件。

## N0014 已处理空标签

遇到没有内容的标签，程序按标签用途和输出设置处理。

例子：`<span></span>` 没有文字；`<p></p>` 可能承担留白作用。

处理：检查段落之间的留白。选择 --profile aggressive 可得到更紧凑的文章。

## N0015 已清理异常字符串

普通正文中出现了 undefinedundefined，程序已清理对应内容。代码块和 code、kbd、samp、var 中的字面文本保持原样。

例子：`undefinedundefined报名通知` 中的异常前缀被移除，保留“报名通知”。

处理：用 --verbose 核对前后文字，确认文章仍完整。

## N0016 已统计段落空白

段落含普通空格、不换行空格或其他空白。程序会识别其中可能用于缩进的部分，输出效果由设置决定。

例子：`<p>&nbsp;&nbsp;报名通知</p>` 用两个不换行空格模拟段首缩进。

处理：需要清理段首空格时选 --profile aggressive；希望保留原排版时检查保守档输出。

## N0017 已处理编辑器扩展属性

网页带有编辑器保存的辅助属性，程序提取可用信息后整理输出标签。

例子：附件上的 `isupload="true"` 表示上传标记，普通附件链接通过 href 保存。

处理：通常无需操作；确认附件或图片链接仍可使用。

## N0018 已跳过样式注释

style 内的注释已在读取样式时跳过，周围的有效声明继续处理。

例子：`color: red; /* 强调 */ font-weight: bold` 保留红色和加粗的样式信息。

处理：无需操作，检查文字效果即可。

## N0019 已按优先级选择样式

同一属性有多个声明时，程序按声明顺序和 !important 标记选择生效值。

例子：`color: red !important; color: blue` 中，红色具有更高优先级。

处理：检查最终采用的值是否符合预期；修改本地 HTML 时可整理重复声明。

## N0020 已读取图片尺寸

图片标签或样式提供了宽高，程序已将其记录为图片的格式信息。

例子：`<img src="photo.png" width="320" height="200">` 提供宽 320、高 200 的尺寸。

处理：检查图片比例。具体显示大小也受输出格式和预设影响。

## N0021 已读取表格样式

表格的宽度、边框等已识别样式被记录下来。

例子：`<table style="width: 100%">` 请求表格占满可用宽度。

处理：在需要使用的输出格式中检查表格宽度及边框效果。

## N0022 已读取表格列宽

表格的列宽声明已提取，用于能够表达列宽的输出格式。

例子：`<col style="width: 30%">` 为某列指定了占表格宽度 30% 的尺寸。

处理：检查列宽比例，尤其是文字较多的单元格。

## N0023 检测到异常字体声明

font-family 中出现了编辑器异常包装。此提示表示检测结果；默认修复字体名，--no-repair-corrupt-fonts 保留原值，--strip-font-family 则移除整个字体声明。关闭修复时仍检查 CSS 语法。

例子：`font-family: 微软雅黑, undefinedMicrosoft YaHeiundefined` 含有损坏的字体名称。

处理：检查输出字体。需要保留原始值时使用 `--no-repair-corrupt-fonts`；需要移除字体声明时使用 `--strip-font-family` 或相应输出预设。

## N0024 已展开段落间距

合写的 margin 声明已拆分为上、右、下、左四个方向的间距，便于生成文档。

例子：`margin: 10px 0` 表示上下各 10px、左右为 0。

处理：检查段落间距。若希望紧凑排版，可使用清理间距的输出设置。

## N0025 已读取段落间距

段落前后或两侧的间距已记录，是否呈现由输出设置决定。

例子：`margin-bottom: 12px` 为段落下方增加间距。

处理：检查段落之间的距离；如有多余空白，可调整输出预设或单项间距开关。

## N0026 已读取单元格样式

单元格的内边距、对齐等已识别样式被提取。

例子：`<td style="padding: 0px">` 表示文字与单元格边缘之间没有额外内边距。

处理：检查表格文字位置和留白。此提示仅说明已读取该样式。

## N0027 已转换 Word 样式

可识别的 Word 专用样式已转换为正文可使用的格式。

例子：`mso-margin-top-alt: 12pt` 被转换为标准的段前间距声明 `margin-top: 12pt`。

处理：检查相应文字和间距；--verbose 可显示具体属性及处理结果。

## N0028 准备重试网络请求

上一次请求遇到可重试的错误，程序即将再次请求同一地址。详情中列出了错误编号和重试次数。

例子：第一次请求超时，出现 E0101，随后开始第 1 次重试。

处理：等待最终结果；可用 --retries 0 关闭重试，或用 --timeout 60 增加单次等待时间。

## N0029 使用 --verbose 查看详情

当前输出省略了逐项处理细节。加 --verbose 可以查看 HTML 上下文、对应输出文字及具体属性。

例子：命令末尾加上 `--verbose`，即可展开附件图标清理或署名判断的详情。

处理：需要检查某处结果时重新运行同一命令并添加 --verbose；仅查询编号含义时使用 --explain。

## N0030 使用 --explain 查看编号解释

本次运行出现了警告或错误，末尾提示给出一个可直接执行的查询命令。

例子：出现 W0005 图片下载失败后，运行 `ue-weave --explain W0005` 可查看原因和处理方法。

处理：复制提示中的命令运行；需要了解其他警告时，将编号替换为对应的 W 或 E 编号。

## W0019 嵌套过深，已提取文本

HTML 超过 256 层或正文块超过 24 层时，该部分按原顺序提取文字，层层嵌套的排版会被展开。

例子：正文被 5000 个 div 包住，输出保留里面的文字，并显示此警告。

处理：检查输出的段落和资源；可用 --selector 选择更靠近正文的容器，或整理输入 HTML 后重新导出。

## N0031 已移除编辑器书签

UEditor 用特定 span 标记光标位置，导出时会移除这些标记及其内容。

例子：`<span id="_baidu_bookmark_start_1">临时文字</span>` 不进入正文。

处理：通常无需操作；如果这里存放了正文，可在输入 HTML 中移除该 id 后重新导出。

## N0032 已还原代码块空格

UEditor 用带 brush 标记的 pre 保存代码，保存时会将普通空格写成不换行空格。导出代码时将其还原为普通空格。

例子：`<pre class="brush:python">&nbsp;&nbsp;print(1)</pre>` 输出保留两个普通空格的缩进。

处理：检查代码缩进即可。普通 pre 中的不换行空格保持原值。

## N0033 已跳过页面分页样式

输入包含孤行控制或分页位置要求，导出使用目标文档自身的分页规则。

例子：`orphans:2;widows:2;page-break-after:avoid` 用于控制打印时段落如何跨页，正文文字保持不变。

处理：需要指定分页时，在 Typst 文档中调整分页；这类样式的原值可通过 --verbose 查看。

## N0034 已保留文档字段的显示文字

sdfield 标签保存页码、日期等文档字段，导出保留当前显示文字。

例子：`<sdfield type="PAGE">3</sdfield>` 导出为文字 3。

处理：核对当前文字；需要自动页码时，在目标文档中设置页码。

## N0035 已读取列表样式

列表的 list-style-type 已写入正文结构。输出格式支持的标记会随列表输出。

例子：`<ul style="list-style-type:square">` 保留方块标记；UEditor 的 dot 和 dash 在 Typst 中使用圆点和短横线。

处理：核对列表标记。其他自定义图案可能同时产生 W0018 或 W0010，详细说明记录具体限制。

## N0036 已使用附件标题补全链接文字

附件链接只有图标或空白，已使用原有 sudyfile-attr、title 或 download 中的标题作为显示文字。

例子：链接仅包含 Word 图标，但 sudyfile-attr 保存了“报名表.docx”，导出使用“报名表.docx”作为链接文字。

处理：核对显示的附件名称。没有标题的空链接保留原地址；可在正文 JSON 中补充文字。

## N0037 已跳过无输出影响的样式

该样式只影响浏览器中的视觉或布局，正文文字、图片和链接不受影响，导出时忽略。

例子：`text-wrap-mode: wrap`、`--size: 12px`、`font-feature-settings: "kern"`、`padding: 4px`。

`white-space: pre*` 和 `display: none` 会影响内容呈现，仍按 W0014 报告。

处理：无需处理。需要核对全部被跳过的声明时，使用 `--verbose` 或查看 JSON 结果中的 notes。
